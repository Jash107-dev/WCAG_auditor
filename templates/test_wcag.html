About This Page

Web accessibility ensures that websites, tools, and technologies are designed and developed so that people with disabilities can use them. This includes people with visual, auditory, physical, speech, cognitive, and neurological disabilities.

The Web Content Accessibility Guidelines (WCAG) 2.1 define how to make web content more accessible. This page follows all four WCAG principles: Perceivable, Operable, Understandable, and Robust.

Key Accessibility Features

Perceivable

All images have descriptive alt text. Color is never the only way information is conveyed.

Operable

All functionality is keyboard accessible. Focus indicators are clearly visible on all elements.

Understandable

Language is declared on the page. Forms have clear labels and helpful error messages.

Robust

Valid HTML with proper semantic structure. Compatible with screen readers and assistive technologies.
